# Recovery Hope

A compassionate, responsive static website for Recovery Hope.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `resources.html` — Resources
- `stories.html` — Stories
- `events.html` — Events
- `get-help.html` — Get Help

## Preview

Open `index.html` in a browser. The site requires no build step or dependencies.

## Safety information

Crisis resources are provided for general awareness. For immediate danger, contact local emergency services. In the United States, call or text 988.
